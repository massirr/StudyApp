## 1.3. Zou + infinitief
Ik zou graag leren dansen.

Ik zou (graag) naar een warm land willen verhuizen.

Je zou de verwarming lager kunnen zetten.

ZOU + INFINITIEF gebruiken we om een wens uit te drukken of om een advies te geven.

> **Regel** *(uit afbeelding p.10)*
>
> 1. Je kan **zou graag + infinitief** gebruiken om een **wens** uit te drukken.
>    Als de eerste infinitief *willen, kunnen, moeten, mogen, gaan, leren* is, kan er nog een tweede (derde) infinitief volgen.
>    - Jean **zou graag** leren koken.
>    - Maria **zou graag** auto's **kunnen repareren**.
>    - Ik **zou graag** in Spanje **willen gaan wonen**.
> 2. Je kan **zou + kunnen + infinitief** gebruiken om een **advies** te geven.
>    - Je **zou** een warme trui **kunnen aandoen**.
>    - Je **zou** de tram **kunnen nemen**.

**Een wens uitdrukken** *(tabel p.10)*

| Patroon | | |
|---|---|---|
| Ik wil | in België / in Spanje / naar Spanje | blijven. / wonen. / verhuizen. |
| **Ik wil** | … | **+ infinitief** |
| Ik zou graag | in België / in Spanje / naar Spanje | blijven. / wonen. / verhuizen. |
| **Ik zou graag** | … | **+ infinitief** |
| Ik zou | in België / in Spanje / naar Spanje | willen blijven. / willen wonen. / willen verhuizen. |
| **Ik zou** | … | **+ willen + infinitief** |

## 1.4. Zouden vs zullen

 Zullen            Een voorstel:                   Zullen we naar de film gaan?

                   Een belofte:                    Dat zal ik doen.

                   Een waarschijnlijkheid:         Hij is vandaag niet op werk, hij zal wel ziek zijn.

                   Toekomst:                       De trein zal vertrekken van spoor 5.

 Zouden            Een fantasie:                   Als ik rijk zou zijn, zou ik een Ferrari kopen.

                   Een beleefde vraag:             Zou ik er even langs mogen?

                   Een advies:                     Je zou beter naar de dokter gaan.

                   Een onzekerheid:                Zou het morgen gaan regenen?

                   Herinnering aan een afspraak:   Jij zou toch boodschappen doen?
