## Context

Subjects are validated JSON files in `src/data/subjects/`, loaded by glob. The model already supports optional per-question `image` (`{ src, alt }`, alt mandatory), `shortText` (auto-graded typed answer with `acceptedAnswers`) and `freeText` (self-graded). Two repo tests constrain new content: correct single-select answers must be spread across A-D within each topic (spread <= 2), and option ids must be positional (`a`, `b`, `c`, `d`).

## Goals / Non-Goals

**Goals:**
- Teach the exam's actual check structure and the Dutch vocabulary, bilingually, before 2026-11-11.
- Ground every procedural claim in a Belgian or Flemish source where one exists.

**Non-Goals:**
- Changing the schema, quiz engine or MCP server; scraping third-party photos; covering the driving test itself.

## Decisions

- **Structure follows the official GOCA Flanders brochure (DOC. 133), not third-party guides.** It splits the checks into *voorzorgen* (precautions), *instellingen* (settings) and *controles*; the controles are *systematisch* (demisting, lights, horn, indicators, brake lights: the candidate operates each in turn) plus *steekproefsgewijs* (one item picked by computer: tyre wear, tyre pressure, engine oil, brake fluid, coolant, washer fluid; 2 min 30 s if the bonnet must be opened, 1 min 30 s otherwise). The Belgisch Staatsblad exam text lists the same items.
- **Belgian rules, not Dutch ones.** The rear fog light threshold is 100 m in Belgium (50 m in the Netherlands); questions state Belgian values and cite Belgian sources. Where Belgian sources disagree on a nuance (heavy rain, minimum visibility for front fog lights) no question tests it.
- **Authoring directly in the repo.** The MCP route cannot express `image`/`shortText`/`freeText` and is currently failing with a GitHub 401, so the JSON is generated by a script and committed. IDs follow the existing convention (`t-N`, `q-N`, `note-N`, `src-N`).
- **Images are original SVG schematics, numbered for the quiz.** Each question image shows numbered markers; the explanation reveals the full NL/EN legend. This avoids copyrighted photos and keeps the picture from giving the answer away. A labelled reference version of each diagram is rendered separately for the user's phone.
- **Answer positions are balanced by construction.** The generator rotates the correct option per topic so the existing distribution test passes without hand-tuning.
- **Vocabulary drills use `shortText`.** Accepted answers include article and synonym variants (e.g. `toeter`, `de toeter`, `claxon`) because the app compares after normalising case and whitespace only.

## Risks / Trade-offs

- **Engine-bay layouts differ per car** -> the diagram is labelled "schematic"; the user should find each item on the actual exam car (a Dutch-speaking supervisor or the rijschool car).
- **How brake lights are verified in the exam is not documented** in the sources -> the content says only that the candidate operates the control and names it, and does not invent a procedure.
- **Some wording of examiner phrases is reconstructed** (the official sources give the check list, not the exact Dutch sentences) -> prompts are marked as typical phrasing, not a transcript.

## Migration Plan

Additive content only. Ships by merging to `master` (Vercel auto-deploy). Rollback is deleting the new files.
